# Logistic Regression Performance Summary

The logistic regression model was trained using the `full` feature set with `C=2.0` and reached `0.9729` training accuracy, `0.8720` validation accuracy, and `0.8830` test accuracy.

On the test set, the strongest class by F1 was `The Persistence of Memory` with precision `0.8852`, recall `0.9474`, and F1 `0.9153`. The weakest class was `The Starry Night` with precision `0.8980`, recall `0.7719`, and F1 `0.8302`.
